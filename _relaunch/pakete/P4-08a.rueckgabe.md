### SIG-2 „Laser zieht den Ablauf“ – Auslegung und Begründung
- **Befund:** `/bad` hat im Bestand **keinen Ablaufabschnitt**; „Ebenheit“, „Restfeuchte“, „Tragfähigkeit“ stehen nicht im Bestandstext der Seite (nur in `processSteps` von `/`). Darum (Briefing) keine Prüfhaken mit diesen Wörtern.
- **Ablauf der Seite:** Die Seite selbst führt in drei Schritten: Konzept wählen (Qualitäts-Kategorien) → Projekt beschreiben („Ihr Badprojekt in vier Schritten beschreiben“) → anfragen („Planen Sie Ihr Traumbad …“, Schritt 1 von 5). Das sind die drei Stationen; ihre vorhandenen Überschriften sind die Schritttitel.
- **Schrittfuge je Station:** Laser zieht die Achse – ab lg als Waage über die volle Inhaltsbreite von links, darunter als Lot am linken Rand über die Station (setzt das Lot des Einstiegs fort, eine durchgehende Achse); am Kreuzpunkt setzt sich das Fugenkreuz, daneben der Prüfhaken auf der Linie. Der Prüfhaken hat keinen eigenen Text (sonst doppelter Text): Sein Titel ist die Überschrift direkt darunter.
- **Auslöser:** IO 30 % an der 32 px hohen Schrittfuge, nicht an der Station (eine Station kann mobil höher als 1/0,3 Bildschirme sein und erreichte 30 % sonst nie). Lot-Linie liegt im Baum der Schrittfuge, positioniert an der Station.
- **Choreografie:** Linie dauer-5 · kurve-laser; Kreuz sofort (dauer-2), Prüfhaken nach 4 × Staffel (240 ms) – gesamt 1200 ms ≤ 1600 ms. Nur transform/opacity (Tailwind-Versatz nutzt `translate`, die Regel `transform` – keine Kollision).
- **S-02:** 3 Scroll-Auslöser bei 6 Abschnitten (Einstieg, Leistungen, 3 Stationen, Abschluss) = die Hälfte; sonst kein `auftritt` auf der Seite.
- **Endzustand** ohne `html.k-bewegung` (reduziert, ohne JS, Zeitlimit) sofort; bis die Regel in `kern.css` steht, zeigt der Entwurf den Endzustand.

**Vorschlag `kern.css`** (nach dem SIG-1-Block einfügen):
```css
/* --------------------------------------------------------------------------
   SIG-2 Laser zieht den Ablauf (K-009, Register `sig-ablauf`, P4-08a): an jeder Schrittfuge einer Station auf /bad
   zieht der Laser die Achse (ab lg Waage von links, darunter Lot von oben), dann setzt sich das Fugenkreuz am
   Kreuzpunkt und der Prüfhaken. Auslöser IO 30 % an der Schrittfuge (data-schwelle="0.3"). Nur transform/opacity.
   Ohne html.k-bewegung (reduziert, ohne JS, Zeitlimit) steht der Endzustand sofort.
   -------------------------------------------------------------------------- */
[data-motion="sig-ablauf"] .k-ablauf-waage { transform-origin: left center; }
[data-motion="sig-ablauf"] .k-ablauf-lot { transform-origin: center top; }
[data-motion="sig-ablauf"] .k-ablauf-waage,
[data-motion="sig-ablauf"] .k-ablauf-lot {
  transition: transform var(--k-dauer-5) var(--ease-k-laser);
}
[data-motion="sig-ablauf"] .k-ablauf-kreuz,
[data-motion="sig-ablauf"] .k-ablauf-haken {
  transition: opacity var(--k-dauer-2) var(--ease-k-setzen), transform var(--k-dauer-2) var(--ease-k-setzen);
}
[data-motion="sig-ablauf"] .k-ablauf-haken { transition-delay: calc(var(--k-staffel) * 4); }
html.k-bewegung [data-motion="sig-ablauf"][data-ausloeser="sicht"]:not([data-sichtbar]) .k-ablauf-waage { transform: scaleX(0); }
html.k-bewegung [data-motion="sig-ablauf"][data-ausloeser="sicht"]:not([data-sichtbar]) .k-ablauf-lot { transform: scaleY(0); }
html.k-bewegung [data-motion="sig-ablauf"][data-ausloeser="sicht"]:not([data-sichtbar]) .k-ablauf-kreuz,
html.k-bewegung [data-motion="sig-ablauf"][data-ausloeser="sicht"]:not([data-sichtbar]) .k-ablauf-haken {
  opacity: 0;
  transform: scale(0.5);
}
@media (prefers-reduced-motion: reduce) {
  [data-motion="sig-ablauf"] * { transition-duration: 0s !important; transition-delay: 0s !important; }
}
```
Begründung der letzten Regel: Die allgemeine Reduziert-Regel trifft nur das Element mit `data-motion`, nicht die Linien darin (ohne `k-bewegung` gibt es zwar keinen Startzustand, die Regel sichert trotzdem ab).
