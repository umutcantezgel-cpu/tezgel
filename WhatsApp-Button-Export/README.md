# WhatsApp Button Export

This directory contains the `FloatingWhatsAppWidget.tsx` component.
You can easily drag and drop this into any Next.js project using TailwindCSS.

## Usage:
1. Copy `FloatingWhatsAppWidget.tsx` to your `components/` folder.
2. Ensure you have the `lucide-react` icons library installed (`npm i lucide-react`).
3. Update the `companyInfo.socialMedia.whatsapp` and `companyInfo.name` variables inside the component to match the new project's configuration, or pass them as props.
4. Import and render `<FloatingWhatsAppWidget />` globally, for example in your `app/layout.tsx` or `components/ClientShell.tsx`.
